# MietMoments Android

Native Android-App für die MietMoments-Verwaltung.

> Dieses Repository ersetzt schrittweise die frühere WebView-App. Die bestehende Server-API bleibt während der Migration kompatibel.

## Zielbild
- Kotlin + Jetpack Compose + Material 3
- Native Wochenplanung, Kunden, Artikel und Locations
- Offline-fähige Synchronisation
- Sichere lokale Einrichtung ohne API-Schlüssel im Repository
- GitHub Actions für reproduzierbare Builds
- Momo als dezentes, animiertes MietMoments-Maskottchen

Die eigentliche Neuentwicklung liegt zunächst auf dem Branch `feature/native-compose-v2`.
